# CSE 275 - Algorithm Solutions

A collection of C programs implementing various algorithms and data structures for CSE 275 coursework.

## Live Demo

📊 **[View Live Demo](https://kuramdasuhemanth7-commits.github.io/cse275/allprograms.html)**

## Programs Included

- Max Subarray Sum (Brute Force, Divide & Conquer, Kadane's Algorithm)
- Median of Two Sorted Arrays
- Find Triplet
- Binary Division
- Counting Sort
- Radix Sort
- Ternary Search
- Trie Data Structure
